# Releasing ORCA Services CakePHP Swagger UI Plugin

## Prerequisites

- A local copy of the plugin
- All changes committed & pushed to the Git repo
- [Git CLI client](https://git-scm.com/downloads)
- [Composer](http://getcomposer.org/download)
- Access to the [Git repo](https://github.com/orca-services/cakephp-swagger-ui)

## The Release Process

- Update translation (i18n), if available
- Update the [change log](../CHANGELOG.md) for the release
- Push the changes to the GitLab repo
- [Tag](https://github.com/orca-services/cakephp-swagger-ui/tags) the revision
- Copy the [change log](../CHANGELOG.md) entries of the released version in raw as [release notes for the new tag](https://github.com/orca-services/cakephp-swagger-ui/releases/new)
